# 🚀 Interview Prep AI

A full-stack AI-powered interview preparation platform built with the MERN Stack and Google Gemini API. It helps users generate personalized interview questions, receive AI-generated explanations, organize interview sessions, pin important questions, and add notes for effective preparation.

---

## ✨ Features

- User Authentication (JWT)
- Create Interview Sessions
- AI-generated Questions & Answers
- AI Concept Explanation
- Pin Important Questions
- Personal Notes
- Dashboard to Manage Sessions
- Responsive UI
- Markdown Rendering
- Syntax Highlighting
- Toast Notifications
- Beautiful Animations

---

Frontend
